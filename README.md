# 📈 Stock Movement Prediction App

An interactive machine learning web application that predicts whether a stock's price is likely to rise or fall based on historical market data. Built with **Python**, **XGBoost**, and **Streamlit**, the project combines data visualization, feature engineering, and predictive modeling into an intuitive user interface.

---

## Overview

This project demonstrates the complete machine learning workflow, from collecting and visualizing historical stock data to engineering predictive features, training an XGBoost classification model, and deploying the model through an interactive Streamlit web application.

Users can search for a stock ticker, explore historical price trends, and receive a model-generated prediction on the stock's expected price movement.

The goal of this project was to demonstrate practical machine learning and data science skills by building an end-to-end stock prediction application. The project emphasizes feature engineering, predictive modeling, data visualization, and deployment within an interactive web interface.

---

## How It Works

1. The user enters a stock ticker.
2. Historical market data is retrieved and processed.
3. Relevant predictive features are engineered from the dataset.
4. Historical price trends are visualized using Matplotlib.
5. The trained XGBoost classifier analyzes the engineered features.
6. The application predicts whether the stock is likely to increase or decrease in price.
7. Results are displayed through an intuitive Streamlit interface.
